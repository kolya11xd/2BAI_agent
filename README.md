# 2BAI_agent
Currently my agent can:
- Search Wikipedia and query scholarly articles (using OpenAlex)
- Parse personal PDFs and notes to answer questions about custom study content
- Retrieve precise dictionary definitions for terms
- Perform mathematical calculations and convert measurement units
- Fetch real-time foreign exchange conversion rates
- Check current weather conditions
- Display current time across any regional time zone

Based on starter code from the Ubucon26 workshop ‘Build a Zero-Cost AI Agent in Your Browser’ by Mr.Nishant Kumar Thakur and Ms.Aishwarya Mathuria.
